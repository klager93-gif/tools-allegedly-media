# Purpose

The Paycheck Calculator is a paycheck planning tool for hourly workers. It estimates work hours, paid leave hours, before-tax pay, itemized taxes, deductions, other adjustments, take-home pay, and effective hourly take-home rate.

---

# Current Features

- Regular hours input.
- Overtime hours input.
- Double time hours input.
- Benefit / paid leave hour selector pills.
- Dynamic paid leave hour rows for vacation, sick, personal, holiday, comp time, bereavement, training, and other paid hours.
- Smooth empty state when no benefit time is entered.
- Hourly rate input.
- Pay period selector.
- Currency selector.
- Overtime multiplier selector.
- Double time multiplier selector.
- Custom multiplier support.
- Add Tax modal.
- Add Deduction modal.
- Add Other Adjustment modal.
- Suggested tax, deduction, and adjustment pills.
- Static Amount / Percentage selector.
- Itemized adjustment lists.
- Before Taxes (Gross) result.
- Regular, overtime, double time, and benefit pay breakdowns.
- Total paid hours result.
- Take-Home Pay (Net) result.
- Effective hourly take-home estimate.
- Copy Results.
- Print Report.
- Saved settings.
- Example values.
- Reset control.
- Shared Signal Labs navigation.
- Disabled hidden ad slots for future monetization support.

# Development Notes

Paycheck v0.3 reorganizes the calculator around how users think about a paycheck:

```text
Hours & Earnings
Pay Details
Deductions & Adjustments
Estimated Paycheck
```

Benefit and paid leave hours are estimated at the regular hourly rate for now. Holiday premium, shift differential, bonuses, and more advanced earnings rules are planned for future Paycheck releases.
