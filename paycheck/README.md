# Purpose

The Paycheck Calculator is a simple first-version paycheck estimator for hourly workers.

It estimates:

- Gross pay.
- Estimated taxes.
- Deductions.
- Take-home pay.
- Effective hourly take-home rate.

---

# Current Features

- Hourly rate input.
- Hours worked input.
- Pay period selector.
- Currency selector.
- Estimated tax rate input.
- Deduction input.
- Take-home pay estimate.
- Copy Results.
- Print Report.
- Saved settings.
- Example values.
- Reset control.
- Shared Signal Labs navigation.
