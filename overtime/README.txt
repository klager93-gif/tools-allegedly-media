Signal Labs Overtime Calculator

README

=====================================================

Purpose

The Signal Labs Overtime Calculator is designed to
provide a clean, modern, and easy-to-use way to
estimate overtime pay and gross earnings.

The long-term goal is to expand the calculator into
a more complete income planning tool capable of
estimating take-home pay, overtime goals, advanced
pay scenarios, and additional financial planning
features.

=====================================================

Current Features

* Hourly rate input
* Hours worked input
* Overtime threshold
* Overtime multiplier
* Regular hours calculation
* Overtime hours calculation
* Regular pay calculation
* Overtime pay calculation
* Total gross pay calculation
* Effective hourly rate
* Example values
* Reset functionality
* Weekly summary
* Changelog popup
* Roadmap popup
