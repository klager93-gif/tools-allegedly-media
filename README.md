# Signal Labs

Useful tools without the noise.

## Current structure

- `/assets/` shared styles, scripts, components, and icons.
- `/standards/` official Signal Labs development standards.
- `/docs/` install, restore, and backup documentation.
- `/build/` build manifests and checksums.
- `/paycheck/` Paycheck Calculator.
- `/pay-planner/` unlinked Pay Planner incubator.
- `/overtime/` Overtime Calculator.
- `/timeoff/` Time Off Planner.
