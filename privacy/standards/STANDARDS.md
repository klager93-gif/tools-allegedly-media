## Source authority

GitHub wins unless a newer user-provided ZIP from the current chat is explicitly approved and not yet represented in GitHub. If confused, clarify.

## Core rules

- Review broadly. Verify specifically.
- Whole files only.
- GitHub title and summary must be provided in chat.
- Public pages should not expose internal build/developer noise.
- Master changelog is append-only across all Signal Labs projects.
