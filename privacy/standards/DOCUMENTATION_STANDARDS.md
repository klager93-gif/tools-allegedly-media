# Signal Labs Documentation Standards

## Changelogs

- `MASTER-CHANGELOG.md` remains at root and is append-only for all Signal Labs projects.
- Each project/tool keeps `PUBLIC_CHANGELOG.md` and `ADMIN_CHANGELOG.md`.
- Regular `CHANGELOG.md` files are deprecated.

## Root organization

- Standards live in `/standards/`.
- Operational docs live in `/docs/`.
- Build artifacts/manifests live in `/build/`.
