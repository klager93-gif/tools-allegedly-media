# Signal Labs Versioning Standards

Versions are independent by project/tool. Home, Paycheck, Pay Planner, Overtime, and Time Off each maintain their own version trees.

## Packaging

Build manifests and checksums live in `/build/` at root, and may also exist inside tool folders when tool-specific packages are produced.

## Version synchronization

Every affected page must have visible and hidden version references checked before release. Footer versions should change only when the page/tool version changes.
