# Pay Planner

**Current Status:** v0.1.x — Incubator

Pay Planner is an unlisted incubator tool for future pay goal planning. It is kept structurally valid so whole-site validation passes, but it is not yet a flagship public tool.

## Current Scope

- Static HTML/CSS/JS only
- No backend
- No stored user accounts
- No production database writes
