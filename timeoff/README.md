# Current Features

- Time Off Planner identity.
- Quick Start presets.
- Category pill selector.

- Projection date and pay period settings.

- Planned Time Off events.
- Policy Rules helpers.
- Warnings and policy notes.
- Planner Summary.
- Copy Results.
- Print Report.
- Saved settings and saved layout state.
- Mobile collapsible cards and results.
