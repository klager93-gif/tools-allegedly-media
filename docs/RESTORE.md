# Restore

Replace included files at matching paths. This focused package does not delete or replace Overtime/Time Off.

## Restore From Release Archive

Use the matching release ZIP in the dated `Releases/` folder as the restore point. Release archives are complete snapshots, so a separate duplicate backup folder is not required for normal releases.

1. Find the desired release ZIP.
2. Extract it into a temporary folder.
3. Compare or replace the current project files as needed.
4. Commit and push after verifying the restore.
