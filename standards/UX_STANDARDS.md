# UI / UX Standards

## Philosophy

> Useful tools without the noise.

## Principles

- Essentials first.
- Advanced options only when needed.
- Avoid developer noise in public UI.
- Avoid duplicate metadata.
- Avoid multiple footers.
- Make interactive controls obvious.
- Design for mobile and desktop.
- Use consistent cards, pills, typography, colors, spacing, and button hierarchy.

## Public Pages

Public pages should feel like website pages, not raw markdown or downloads.

Use real pages for:

- changelog
- roadmap
- how-to
- report issue
- request feature
- contact
- about
- privacy
- terms
- status

## Metadata

Version/theme/status metadata should not clutter tool heroes or results cards.

Use footer/status areas or internal docs instead.
