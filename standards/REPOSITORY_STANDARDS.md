# Repository Standards

## Root Files

Keep front-desk files at root:

- index.html
- README.md
- ROADMAP.md
- HOWTO.md
- PUBLIC_CHANGELOG.md
- ADMIN_CHANGELOG.md
- MASTER-CHANGELOG.md
- MASTER-ROADMAP.md

## Root Folders

Preserve all live top-level folders, including unchanged tools, during full replacements.

## Support Folders

- standards/
- docs/
- build/
- assets/
