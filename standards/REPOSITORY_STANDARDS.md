# Repository Standards

## Root Folders

Live top-level folders should be preserved.

Expected structure includes:

```text
about/
assets/
build/
changelog/
contact/
docs/
how-to/
overtime/
pay-planner/
paycheck/
privacy/
report-issue/
request-feature/
roadmap/
standards/
status/
terms/
timeoff/
```

## Root Files

Keep root front-desk files at root:

```text
index.html
README.md
ROADMAP.md
HOWTO.md
PUBLIC_CHANGELOG.md
ADMIN_CHANGELOG.md
MASTER-CHANGELOG.md
MASTER-ROADMAP.md
```

## Supporting Folders

Operational docs:

```text
docs/
```

Build metadata:

```text
build/
```

Standards:

```text
standards/
```
