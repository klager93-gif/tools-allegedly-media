## Summary

Schedule v1.9.0 adds the Assignments Foundation. This release connects employee records to operational assignment records so future minimum staffing, time-off validation, VOT bidding, mandation, and schedule generation can reason about where employees belong.

## Added

- Assignment template seed data
- Employee assignment seed data
- Assignment service/repository/adapter boundaries
- Assignment read API contract
- Future Postgres assignment schema
- Assignments Foundation preview section in the Schedule UI
- Assignment foundation documentation

## Not Added

- No production assignment editor
- No assignment write routes
- No authentication/login system
- No schedule generation engine
- No VOT bidding workflow
- No Paycheck changes
