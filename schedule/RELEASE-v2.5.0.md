# Signal Schedule v2.5.0 — Coverage Board Foundation

## Summary

Adds the admin-first Coverage Board foundation. The board compares assigned staffing against minimum, target, and maximum staffing, flags below-minimum rows, and links uncovered work to the Overtime Opportunity Board where available.

## Added

- Coverage Board page
- Coverage Board preview data
- JSON adapter, repository, and service layer
- Coverage summary cards
- Coverage filters
- Daily grouped coverage rows
- Minimum/target/max staffing display
- Assigned and available employee preview chips
- Linked OT opportunity action
- Coverage read contract
- Future Postgres schema preview

## Notes

This is still a preview foundation. No production approvals, scheduling writes, OT awards, or employee notifications are active yet.
