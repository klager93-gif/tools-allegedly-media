# Schedule v2.2.1 — Request Hours & Admin Override Foundation

## Summary

Adds request hour calculation planning to Leave Requests and prepares the same rules for future Open Shifts / VOT workflows.

## Added

- Full-day vs partial-day request mode.
- Start time and end time fields.
- Calculated hours preview.
- Scheduled shift hours support for full-day requests.
- Request type increment settings.
- Admin/Scheduler override planning for exact time entries.
- Override reason/audit trail planning.
- Shared RequestHoursService.
- Read-only request increment settings API planning.
- Future SQL planning migration.

## Not Active Yet

- No production leave writes.
- No real authentication or role enforcement.
- No balance deduction.
- No live approval workflow.
