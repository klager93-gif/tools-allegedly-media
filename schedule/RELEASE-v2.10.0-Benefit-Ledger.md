# Schedule v2.10.0 — Benefit Ledger

Adds the Benefit Ledger foundation to Signal Schedule.

## Highlights

- Added benefit bank preview for vacation, sick, personal, comp time, and holiday balances.
- Added request impact previews showing before/after balances.
- Added manual adjustment and audit trail preview.
- Added admin-editable calendar shortcode foundation for compact week/month labels.
- Added JSON data, adapter, repository, service, API contract, and Postgres SQL foundation.
- Updated Schedule navigation across pages.

## Calendar Shortcodes

Built-in examples include VAC, SP, SF, P, CT, HOL, VOT, and T. Admin-defined shortcodes are planned as configurable records.
