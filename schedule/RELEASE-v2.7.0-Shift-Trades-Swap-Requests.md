# Schedule v2.8.0 — Shift Trades & Swap Requests

Adds the Shift Trades & Swap Requests foundation to Signal Schedule.

## Highlights

- Added shift trade, swap, giveaway, and partial trade preview page.
- Added coverage impact, qualification checks, overtime warning, and admin recommendation fields.
- Added trade request queue filters for pending, warnings, below-minimum, and draft items.
- Added ShiftTrade adapter, repository, and service foundation.
- Added API contract and Postgres SQL foundation.
- Updated Schedule navigation so the trade page is reachable across the Schedule subsystem.
- Preserved calendar shortcode planning for a later release.

## Status

Preview only. No production write actions are connected in this release.
