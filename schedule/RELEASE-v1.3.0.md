# Signal Schedule v1.3.0 — D1 Database Foundation

Adds the first Cloudflare D1 database foundation while keeping the active Signal Schedule app static, browser-only, and backend-portable.

## Included

- D1 schema for agencies, employees, and audit logs.
- D1 seed data based on existing pretend multi-agency JSON records.
- Planned D1 adapter contract.
- Updated Cloudflare data layer and API planning documentation.

## Not included

- No live D1 binding.
- No credentials.
- No CRUD.
- No authentication.
- No live writes.
- No new dashboard preview panels.
