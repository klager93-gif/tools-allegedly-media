# Signal Schedule v1.0.0 — Cloudflare Data Layer Foundation

## Summary

Adds a static, browser-safe, multi-agency JSON data layer.

## Included

- `/schedule/data/agencies.json`
- `/schedule/data/employees.json`
- static data loading service functions
- agency selector for pretend agency switching
- employee records carrying `agencyId`
- Rule 24 backend portability preserved

## Not included

- no D1 database
- no Workers/Pages Functions
- no credentials
- no CRUD
- no authentication
- no new dashboard preview panels
