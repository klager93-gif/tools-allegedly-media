# Schedule v2.8.0 — Training & Certifications

Adds the Training & Certifications foundation to Signal Schedule.

## Highlights

- Added Training & Certifications preview page.
- Added certification status, expiration, training, restriction, and admin action previews.
- Added role/credential rule builder preview.
- Added JSON data, adapter, repository, and service layers.
- Added API read contract and Postgres SQL foundation.
- Updated Schedule navigation across pages.

## Notes

This is an admin-first read-only foundation. Future releases should connect credential requirements to coverage, overtime opportunities, trades, assignments, calendar labels, and approval rules.
