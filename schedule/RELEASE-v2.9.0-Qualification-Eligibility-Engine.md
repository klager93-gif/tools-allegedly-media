# Schedule v2.9.0 — Qualification & Eligibility Engine

Adds the Qualification & Eligibility Engine foundation to Signal Schedule.

## Highlights

- Adds optional credential requirements for shifts, spots, open OT, trades, and assignments.
- Pulls eligibility status from Training & Certifications records.
- Previews eligible, warning, and blocked states.
- Adds admin override/audit foundation for emergency staffing exceptions.
- Adds data, adapter, repository, service, API contract, and Postgres SQL foundation.
- Updates Schedule navigation to include Eligibility.

## Notes

This release makes v2.8 useful by connecting training data to staffing decisions.
