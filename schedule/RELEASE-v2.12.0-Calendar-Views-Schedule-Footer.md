# Schedule v2.12.0 — Calendar Views + Schedule Footer

Adds user-facing week and day calendar views and a lightweight Schedule-specific footer across Schedule pages.

## Highlights

- Added week calendar grid using admin-managed shortcodes.
- Added day/detail view with expanded event text, coverage status, and hour summaries.
- Added Schedule-specific footer component and CSS.
- Applied footer across Schedule pages.
- Fixed overview version drift from earlier releases.
- Added Calendar View data, adapter, repository, service, API contract, and SQL foundation.

## Status

Read-only foundation. Production database writes, authentication, and final approval actions remain disabled until later backend releases.
