# Schedule v2.6.0 — Seniority & Rotation Engine

Signal Schedule v2.6.0 adds the Seniority & Rotation Engine foundation.

## Added

- Seniority & Rotation page
- Equalized OT/callback/mandate preview metrics
- Eligible, skipped, callback, and mandate filters
- Ordering rule preview
- Skip reason and audit trail preview
- Seniority data, JSON adapter, repository, and service
- API read contract
- Postgres SQL foundation

## Navigation

Schedule navigation now includes Seniority & Rotation across the Schedule section.

## Roadmap Note

Calendar short codes are captured for a future release: VOT, T, SP, SF, VAC, CT, and admin-defined custom codes.
