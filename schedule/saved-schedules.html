v4.6 scope

  • Builder can save a draft schedule to the protected API.
  • Saved Schedules page can list and inspect database-backed drafts.
  • Open-in-builder uses local handoff storage so the UI can preview the selected draft before full engine integration.
  • Protected publish action is exposed with an ADMIN_API_KEY prompt.
  • Copy buttons are available for schedule IDs, agency IDs, endpoints, and JSON/detail fields.
  • Protected rename/delete actions remain API-ready but are intentionally not exposed without the admin key flow.
